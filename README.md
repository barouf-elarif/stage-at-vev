# stage-at-vev

Site web personnel d'**Elarif Barouf**, élève en 1CIEL au lycée Eucalyptus à Nice, réalisé pendant mon stage chez **VEV** (logiciels de gestion pour la recharge de véhicules électriques).

Ce dépôt regroupe tout mon travail du stage : mon CV en ligne, mes centres d'intérêt et mon journal de stage.

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | Page principale : profil, compétences, formation, langues, centres d'intérêt, projets, journal de stage et contact |
| `interets.html` | Page détaillée de mes centres d'intérêt : échecs, jeux vidéo, animés |
| `style.css` | Feuille de style commune aux deux pages |
| `stage.txt` | Journal de stage, jour par jour |

## Fonctionnalités

- **Trois langues** : français, anglais et espagnol. On change de langue avec les drapeaux en haut de la page ; le choix est gardé en mémoire (`localStorage`).
- **Centres d'intérêt interactifs** : un clic sur un intérêt affiche plus d'informations.
- **Site statique** : uniquement du HTML, du CSS et un peu de JavaScript, sans dépendance ni outil de build.

## Voir le site

Il suffit d'ouvrir `index.html` dans un navigateur :

```bash
xdg-open index.html
```

## Outils utilisés

- Linux Fedora 44
- VS Code et Claude
- Git et GitHub
